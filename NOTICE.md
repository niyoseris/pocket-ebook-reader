| Component | Licence | Use | Notes |
|---|---|---|---|
| **ESP32 Arduino Core** (espressif/arduino-esp32) | LGPL-2.1 | The framework the firmware runs on | Downloaded by PlatformIO; no copy in the repository |

## Third-party material included in the source code

| File | Source | Licence | What was taken |
|---|---|---|---|
| `firmware/src/epd_lut.h` | **Waveshare e-Paper** reference driver<br>`github.com/waveshare/e-Paper` | **MIT** | The SSD1680 init register array and the partial-refresh LUT tables — **verbatim**, with the source URL recorded at the top of the file |

These tables were not invented: a partial refresh needs a panel-specific
waveform, and a wrong table damages the panel gradually. The source and licence
stay at the top of the file.
